## TL;DR

On-Policy Self-Distillation（OPSD）は、凍結した自身のコピーに「答え」や「解法」を見せた上で、学生モデルのロールアウトを評価させる手法だ。教師に追加情報を与えれば、学生にとって学ぶべきことが増える──そう思える。だが、**その追加情報が蒸留そのものを超えてどれだけ貢献するのか**は、これまで体系的に分離されてこなかった。

Zhang et al. は **AMPLE-Math** という再利用可能なベンチマーク（5,319問 × 6推論ビュー）を構築し、各ビューと無参照蒸留をマッチさせて比較した。結果は鮮やかだ。**Qwen3-1.7B では、思考有効教師が直接応答学生を評価するだけの無参照蒸留が、改善の大部分を占める。** Clean Solution だけが控えめな追加寄与を示し、Full Trace は逆に外部汎化を損なう場面すらある。しかも、**同じ教師・同じ参考情報でも、学生のロールアウトを直接応答から思考有効に変えると、改善が損失に反転する**──参考は変わらないのに。

この一連の発見が示す教訓は、**特権情報の価値は「解法をどれだけ明かすか」ではなく、「学生の試みに対して何を加えるか」で決まる**ということだ。

## 背景

### On-Policy Self-Distillation（OPSD）とは

OPSD は、言語モデルの後段訓練において密なトークンレベルの教師信号を得るための手法だ。大枠はこうなる：

- **学生** $\pi_\theta$：問題 $x$ だけを見て、推論設定 $m_S$ で応答 $y$ を生成する
- **凍結教師** $\pi_{\bar\theta}$：同じ問題に加え、**特権情報** $z_v(x)$ を与えられ、推論設定 $m_T$ で学生の応答プレフィックスを評価する
- **損失**：教師と学生のトークン分布を前向き KL で整列させる

特権情報 $z_v(x)$ の中身は、答えのみ（Answer Only）から完全な推論過程（Full Trace）まで幅広い。直感的には、教師に与える情報が豊富なほど、学生にとって有益な監督が得られるはずだ。しかし、OPSD にはもう一つの経路がある──**思考有効教師が直接応答学生を評価する「跨モード蒸留」**だ。特権情報を与えなくても、この経路だけで改善が起きるなら、特権情報の寄与は見かけよりずっと小さい。

### 分離されてこなかった問い

先行研究は、OPSD が有効であること、特権情報が役立つこと、をそれぞれ報告してきた。だが「蒸留そのものの改善」と「特権情報による追加の改善」を同じ設定で分離した実験はなかった。それには、**同じ答えに到達する多様な推論表現を統制したデータセット**が必要だが、それが存在しなかった。

AMPLE-Math は、まさにこの欠落を埋めるために構築された。

## 方法详解

### AMPLE-Math：5,319問 × 6推論ビュー

AMPLE-Math は、OpenThoughts-114k を源とする5,319の数学問題からなる。各問題に対し、**同じ検証済み答えに到達する6つの推論ビュー**を用意する：

| ビュー | 平均トークン長 | 内容 |
|--------|--------------|------|
| Answer Only | 13 | 答えのみ。推論体なし |
| Gist | 76 | 核心的手法の短段落 |
| Key Points | 284 | 有序なステップリスト |
| Clean Solution | 526 | 精修された書き上げ解法 |
| Summary | 841 | 叙事体の要約 |
| Full Trace | 4,916 | 完全な推論過程（自己検査含む） |

![AMPLE-Math の6つの推論ビュー](/images/ample-math-opsd-privileged-information/fig1.png)

各ビューは Qwen3.6-35B-A3B で生成・精修され、表面検証（完遂性・フォーマット・プロンプト漏洩）と源忠実度審査（無支持表明・後構推論・確信度昇格の排除）を経ている。問題の難度は3つの評価モデルと二項 Rasch モデルで推定され、訓練・開発・テストに層化分割される。

### 統制された実験設計

論文の核心は、**6つのビューを教師の特権情報として与えた場合と、特権情報を与えない（reference-free）場合を、同じ教師・同じ学生・同じ評価設定で比較する**ことだ。さらに、**誤答制御**（別問題の答えを特権情報として与える）も加え、次の3層を比較する：

1. **Reference-free**：特権情報なし。思考有効教師が直接応答学生を評価
2. **誤答制御**：無関係な答えを特権情報として与える
3. **6ビュー**：正しい特権情報を各ビューで与える

この設計により、「蒸留そのものの改善」「マッチした長さを持つ無関係参考の効果」「正しい参考の追加効果」を段階的に分離できる。

### OPSD 損失の定式化

論文では OPSD 損失を次の形で定義する：

$$\mathcal{L}_v(\theta; m_S) = \mathbb{E}_{x,\,y \sim \pi_\theta(\cdot|x; m_S)} \left[ \frac{1}{|I(y)|} \sum_{t \in I(y)} D_{\mathrm{gKL}}\!\left(p^T_{v,t} \| p^S_t\right) \right]$$

ここで $D_{\mathrm{gKL}}$ は教師→学生の前向き KL を各語彙項で上から 0.05 に裁断したもの。この裁断は、教師の極端な確率が学生の訓練を支配するのを防ぐ。

### 正確性整列 $C_v$：教師の診断

教師が「正しい応答には高い確率、誤った応答には低い確率」を与えているかを測る指標として、**正確性整列** $C_v$ を定義する：

- 正値：正しい応答が誤った応答より大きな確率シフトを受けている
- 負値：逆転している

この指標が、Full Trace で**直接応答プレフィックスでは正、思考有効プレフィックスでは負**に反転する現象が、後述の転移反転の鍵となる。

## 実験結果

### Qwen3-1.7B：蒸留成功 ≠ 参考有用

Table 1 の結果が語るのは、意外なほど明確なメッセージだ：

| 参考 | Step 100 域内改善 (pp) | Step 50 外部改善 (pp) |
|------|----------------------|---------------------|
| Reference-free | +1.80 [0.20, 3.47] | +4.07 [1.73, 6.54] |
| Wrong Answer | +1.67 [0.07, 3.32] | +4.14 [1.33, 7.07] |
| Answer Only | +2.41 [0.86, 3.99] | +3.73 [1.27, 6.41] |
| Clean Solution | +3.10 [1.54, 4.73] | +4.91 [2.04, 7.96] |
| Full Trace | +2.38 [0.91, 3.86] | +2.29 [-0.16, 4.88] |

![Qwen3-1.7B: 特権情報別の蒸留改善](/images/ample-math-opsd-privileged-information/fig2.png)

重要な観察を順に挙げる：

1. **Reference-free だけで +1.80pp**：特権情報なしでも、思考有効教師が直接応答プレフィックスを評価するだけで改善が起きる
2. **誤答制御でも +1.67pp**：無関係な答えを与えても、ほぼ同程度の改善──マッチした長さの参考は、内容に関わらず蒸留を助ける
3. **Clean Solution だけが控えめに上回る**：+1.30pp の追加寄与（95% CI [0.20, 2.41]）だが、Holm 多重比較校正を通らない
4. **Full Trace は外部で最弱**：AIME 2025 で +0.49pp、HMMT で +0.42pp と、長い参考ほど汎化を損なう傾向

### SmolLM3-3B：Full Trace だけが step 50 で差をつける

Qwen とは対照的に、SmolLM3-3B では **Full Trace が step 50 で reference-free を約2.0pp 上回る**。ただし step 100 では全構成が凍結基線を下回り、無参照学生の無応答率が ~20% から ~40% に悪化する。このモデル規模差は、**小規模モデルほど長い参考で教師の質が変わる**こと、同時に**訓練の安定性が脆い**ことを示唆する。

### ロールアウトの反転：同じ参考、逆の結果

最も衝撃的な結果はここだ。Answer Only・Clean Solution・Full Trace の3ビューについて、学生のロールアウトを**直接応答から思考有効に切り替える**と──教師も参考も評価もそのままに──**step 50 で全ビューの改善が損失に反転する。**

![直接応答 vs 思考有効 rollout の反転](/images/ample-math-opsd-privileged-information/fig3.png)

なぜか。理由は複合的だ：

- 思考有効ロールアウトは継承された 1,024 トークンの損失窓を超える長さになり、教師の監督が応答の冒頭部分にのみ集中する
- 推論モード・視野・被監督比率が同時に変わる
- **正確性整列 $C_v$ がプレフィックスの種類で反転する**──Full Trace は直接応答プレフィックスでは正だが、思考有効プレフィックスでは負

つまり、**参考は同じでも、それが監督する学生の試みが変われば効果は逆転する。**

### 改善は「まだ解けない問題」に集中

改善の分布を見ると、**基線の直接応答で一度も正解しない（4回中0回成功）が、思考有効では62%で解ける問題**に最大の改善が集中している。これは「新しい能力を教える」より「既存の能力へのアクセスを改善する」という解釈を裏付ける。

## 考察

### 跨モード転移：OPSD の真の働き

一連の証拠が指し示す OPDS の本質は、**直接応答と思考有効の両モードが共有するパラメータを通じた跨モード転移**だ：

![OPSD の跨モード転移メカニズム](/images/ample-math-opsd-privileged-information/fig4.png)

1. 思考有効教師が直接応答プレフィックスを評価 → 密なトークンレベルの信号を生成
2. その信号が共有パラメータを更新 → 直接応答と思考有効の両方で性能が向上
3. 特権情報は、この跨モード転移に何を加えるかで評価されるべき

この解釈を支える証拠は四つある：

- **無参照蒸留で大部分の改善が得られる**──跨モード経路だけで十分
- **直接応答ロールアウトが有効な転移载体**──思考有効ロールアウトに変えると反転
- **改善は基線が「ときどき解ける」問題に集中**──アクセス改善のパターン
- **正確性整列がプレフィックスの種類で反転**──監督の質が学生の試みに依存

### 修正マーカーは見かけより重要でない

Full Trace に含まれる「wait」「but」「check」などの修正マーカー（reconsideration markers）は、推論過程の自己訂正を担うように見える。論文は、これらのマーカーの損失を排除・低減する介入実験を行ったが、**マーカー使用率も精度もほぼ変わらない**ことを示した。修正マーカーへの損失圧力は、改善の駆動力ではない。

### 損失窓と停止時刻の罠

論文は、損失窓の設計（最初の4K vs 分散1K）についても介入実験を行っている。結果：**チェックポイント選択が、表見上の損失窓効果の大部分を説明する。** 同じ step 25 で比較すると、表見上の優位は1pp 以下に縮小する。停止時刻こそが表見上の改善の主因であり、損失窓そのものの寄与は限定的だ。

### 不関連参考は長さをマッチしても効かない

Clean Solution と Key Points について、正しい参考を別問題の参考に差し替えると、**約2pp の精度低下が起きる**。マッチしたトークン長ではこの効果は消えない──**参考の内容が重要であり、長さだけでは不十分**だ。

## 関連研究

### On-Policy Distillation 系

- **OPD / Online EMD**（Agarwal et al., 2024）：分布ズレを避けるための在策蒸留の先駆。AMPLE-Math は、OPD の改善を「蒸留そのもの」と「特権情報」に分離する
- **RISE**（Li et al., 2026, arXiv:2609.05295）：RLVR 軌跡の外挿で合成教師を構築する再帰改善。AMPLE-Math は外挿ではなくビューの比較で教師の質を分解する
- **Aha-Flow Distillation**（arXiv:2609.07036）：Flow Marker の見落としを正す選択的蒸留。AMPLE-Math は選択性ではなく特権情報の寄与に焦点を当てる

### RLVR 系

- **DeepSeek-R1 / DAPO / GRPO**：結果レベルの報酬だけを用いる RLVR と、トークンレベルの密な監督を提供する OPSD は補完的。AMPLE-Math は、OPSD における跨モード経路の重要性を示すことで、両者の協調設計に新たな視点を提供する

### 蒸留の選択性と学習率

- **Selective OPD / Selector-Rate Entanglement**（arXiv:2609.22109）：選択的蒸留で学習率が選択器の優劣判定を覆す現象。AMPLE-Math の損失窓実験と同様、「無邪気な統制は統制ではない」という教訓を共有する

## まとめ

AMPLE-Math が明らかにした事実を、三つの命題に整理する：

1. **蒸留の成功と参考の有用性は別物**──Qwen3-1.7B では、無参照蒸留だけで改善の大部分が得られる。特権情報の追加寄与は、Clean Solution で控えめ、Full Trace では汎化を損なうことすらある

2. **参考の価値は学生の試みが決める**──同じ教師・同じ参考でも、学生のロールアウトを直接応答から思考有効に変えると、改善が損失に反転する。正確性整列 $C_v$ がプレフィックスの種類で反転する現象が、この転移の鍵だ

3. **OPSD の本質は跨モード転移**──思考有効教師が直接応答学生を評価する経路が、共有パラメータを通じて両モードの性能を改善する。特権情報の価値は「解法をどれだけ明かすか」ではなく、「この跨モード転移に何を加えるか」で測られるべきだ

この見方は、OPSD と RLVR の協調設計にも示唆を与える。もし跨モード転移が主経路なら、RLVR で結果報酬を与えつつ OPSD でトークンレベルの密な監督を補完する構成で、**両者の補完性を最大限に引き出せる**はずだ。
